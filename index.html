Voltage drop, explained

Voltage drop is the loss of voltage along a conductor as current travels through it — longer runs and smaller wire both increase it. Too much drop means motors run hot, lights dim, and equipment underperforms, even if the circuit is otherwise correctly rated.

The NEC doesn't make voltage drop a hard code violation in most residential and commercial branch circuits, but it recommends staying under 3% for a branch circuit and 5% total for feeder plus branch combined — the two figures this tool checks your run against.

If your run fails, the fix is almost always to move up one or two wire sizes, shorten the run, or split a long run with a junction closer to the load.

Calculated using the NEC Chapter 9, Table 8 method: VD = (2 × K × I × D) ⁄ CM for single-phase, and VD = (1.732 × K × I × D) ⁄ CM for three-phase, where K is 12.9 Ω·cmil/ft for copper and 21.2 Ω·cmil/ft for aluminum. This is a planning estimate — verify against local code and actual conditions before final sizing.
